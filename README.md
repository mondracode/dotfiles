# Dotfiles

Personal macOS configuration files.

## AeroSpace

The AeroSpace configuration lives at `.config/aerospace/aerospace.toml`.

To use it:

```sh
ln -sf "$PWD/.config/aerospace/aerospace.toml" "$HOME/.config/aerospace/aerospace.toml"
```

## Neovim

The Neovim configuration lives at `.config/nvim`.

To use it:

```sh
ln -sfn "$PWD/.config/nvim" "$HOME/.config/nvim"
```
